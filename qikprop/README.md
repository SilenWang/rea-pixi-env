# QikProp 8.8 分子性质算法说明

对象：Schrödinger 2026-2 Linux 套件里的 `qikprop-v8.8-Linux-x86_64.tar.gz`（VYB-2602 分享 `REA`）。

方法：纯静态分析。REA 6.4.0 + Ghidra 12.1.4（本仓库 pixi 环境）反编译 `qikprop` ELF（stripped，`.text` 378 KB，414 个函数），对照软件自带的参数文件和输出样本复核数值。没有运行软件本体。

合规：分享包里的 `26-2-linux_extract_to_install_dir.tar.gz` 是授权补丁（替换 `libmmfileshared.so`、塞伪造 license），本文全程未使用；仓库只收推导出的数值关系、地址和脚本，不含原软件文件。

## 结论

| 性质 | 口径 | 参数/公式 | 定位 | 复现 |
|---|---|---|---|---|
| `#stars` | 24 个主描述符的"95% 药物"区间，超界各记 1 分 | `params/stars.tsv` | `data/QPlimits` 第 18–64 行 | QPxpd1 **504/504** |
| `SASA` | 探针半径 1.4 Å 的溶剂可及面积，按原子类别拆四块 | `SASA = FOSA+FISA+PISA+WPSA` | `FUN_0040ee10 @ 0x40ee10` | sample **908/908** |
| `QPlogPo/w`（非烃） | 49 描述符分段线性模型 | `params/logp_fit1.tsv` | `main @ 0x414860`，块 `0x4157ed` | QPxpd1 **415/504** |
| `QPlogPo/w`（烃） | 同上模型族，独立一段 | `-0.640392 + 0.009165·volume` | `0x4156aa..0x4156c6` | sample **18/18** |

## 1. `#stars`

口径：不是加权求和，就是把 24 个主描述符逐个和 `data/QPlimits` 里的区间比，落在区间外记 1 分。区间即"95% 已知药物"的范围，可在 `QPlimits` 里改，软件读的是每条"standard is:"下一行的两个数值。

参数表：`params/stars.tsv`（含 QPlimits 行号）。一处坑：EA 的说明行（第 44 行）写 `-0.7 / 1.7`，下一行的实际取值是 `-0.9 / 1.7`，本版本按 **-0.9** 解析——用 -0.9 时 QPxpd1 才 504/504。样例 `qiksim/sample/QP.CSV` 更像按 -0.7 生成（750/908 命中，-0.7 时 766/908），说明该样本与 8.8 不是同一版本。

`PSA`（7–200）也在 24 项里；`QP.CSV` 样本没有 PSA 列，用它只能复核 23 项，多出来的那颗星基本都是 PSA<7 的非极性分子。

复现：`QPxpd1.CSV` 504 个分子，全部一致（`|Δ|<0.0015` 无需，整数相等）。

## 2. SASA 家族

口径：溶剂可及表面积。每个原子按 vdW 半径 + 1.4 Å 探针求出扩展球，球心距离小于半径和的原子对做解析球面削减（不是网格采样），得到暴露面积；再按原子化学类别分别累加。

定位（`FUN_0040ee10 @ 0x40ee10`）：

- `DAT_07935f20 = 1.4`（探针半径，函数入口即赋值），随后把每个原子半径 +1.4，积分完再 -1.4 还原。
- 调用 `FUN_00411c70 @ 0x411c70` 做球面解析积分。
- 累加器：`DAT_07939f60/68/70/78` = FOSA / FISA / PISA / WPSA 面积，`0x7939f80..98` = 对应体积，`DAT_07937e78` = 分子体积（`DAT_07937e68` = 总面积）。
- 原子半径表不在本二进制：从 mmshare 的原子类型拷进 `DAT_0048c000` 起（`FUN_0040ee10` 内 `*(double*)(&DAT_07938020+off) = *(double*)(&DAT_0048c000+off)`）。
- 找不到类型时走 `"COULD NOT FIND SASA TYPE FOR AMBER TYPE"` 分支。

复现：`SASA = FOSA+FISA+PISA+WPSA` 在 908 个样本分子上逐行成立（容差 0.02 Å²）。

## 3. `QPlogPo/w`

口径：分段线性模型，输入是同一份 49 描述符，按溶质类别选段，最后把 9 个槽位相加（`DAT_00509640..DAT_00509680`，求和点 `0x414860` 附近）。非烃段与 `data/QPmyfits` 第 9–49 行的示例完全一致：

```
QPlogPo/w = -0.7049
          - 0.5270 · #amine   - 0.6256 · #amide   + 0.5157 · #acid
          - 0.006921 · FISA   + 0.001171 · PISA   + 0.003815 · WPSA
          + 0.006524 · volume - 0.2999 · donorHB  - 0.4870 · accptHB
          + 44.36   · (Ac·√Dn / SA)
```

分支（都在 `main` `FUN_00414860 @ 0x414860`）：

| 分支 | 判据 | 结果 | 地址 |
|---|---|---|---|
| 非烃 | 有 H 键给/受体 | 上式，常数 -0.7049 | `0x4157ed..0x415834`，常数 `0x4611d8` |
| 两性离子 | 上式且 `#acid>0 && #amine>0` | 常数换成 -2.5789（= -0.7049 − 1.874） | `0x415830..0x415893`，常数 `0x4611d0` |
| 烃 | 无极性基团 | `-0.640392 + 0.009165·volume` | `0x4156aa..0x4156c6`，常数 `0x461230`/`0x461228` |

系数在 `.rodata` 的位置：`0x45f800` -0.2999、`0x45f808` -0.487、`0x45f810` 0.006524、`0x45f818` 44.36、`0x45f820` -0.527、`0x45f828` -0.6256、`0x4611b0` -0.006921、`0x4611b8` 0.5157、`0x4611c0` 0.003815、`0x4611c8` 0.001171。代码用 `mulpd` 一次吃一对相邻常数，所以 `0x45f800/08`、`0x45f810/18` 是成对取的。

复现：烃段 18/18（样本里全部 18 个无极性分子）；非烃段在 QPxpd1 上 415/504（82%）。反编译里还能看到另外两段线性式（常数 -1.374415 / -2.623194，`0x461200` / `0x461220`），对应 FISA 或 accptHB 缺失的溶质，本次没有拆开，所以这 18% 不要当成已验证。

## 4. 复现

```bash
# 1) 取包（分享内 2026-2_Advanced_Linux_part1.zip 的 qikprop 成员即可，1.4 MB）
# 2) 解包后：
pixi run qp-verify -- --data-dir /path/to/qikprop
```

期望输出：

```
PASS  star count (QPxpd1)                            504/504
PASS  SASA = FOSA+FISA+PISA+WPSA                     908/908
PASS  QPlogPo/w hydrocarbon branch                   18/18
PASS  QPlogPo/w fit1 + zwitterion branch (QPxpd1)    415/504
```

脚本只读软件自带的 CSV 和参数文件，不联网、不需要 license。

## 5. 没覆盖的部分

- MW / dipole / IP / EA / polarizability / logS / logHERG 等没有逐项解码；MW 的原子质量表不在这个二进制里（在 mmshare），本包里搜不到 `12.011` 一类字面量。
- `QPlogPo/w` 还有约 18% 的分子走未拆的分支；`RuleOf5` 按 Lipinski 四项复算有 13/504 对不上（软件还看了别的因子），`RuleOf3` 差异更大，都没算命中。
- 全部结论来自静态分析与软件自带样本；没有用授权补丁跑过真实计算，所以没有"跑一遍软件对答案"这一层验证。
